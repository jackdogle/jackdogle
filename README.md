## 🩸 Tentang Saya

Saya **jackdogle**, pendiri & developer di balik **Darkness Community Indonesia**, sebuah server FiveM (GTA V Roleplay) yang saya bangun dan kelola dari awal — mulai dari infrastruktur jaringan, sistem role Discord, hingga pengembangan resource dan aset kustom.

- 🖤 Fokus saat ini: administrasi server, scripting FiveM (Lua), automasi bot Discord, dan infrastruktur jaringan/hosting
- 🧪 Sedang eksplorasi: optimasi performa server & sistem keamanan anti-cheat
- 🎨 Juga mengembangkan aset kustom (custom ped modular) menggunakan Python/Blender (`bpy`)
- 🤝 Terbuka untuk kolaborasi di bidang pengembangan resource FiveM dan tools komunitas roleplay
- 💬 Hubungi saya lewat Discord komunitas di bawah untuk diskusi kolaborasi atau pertanyaan seputar server

> *"Built in the dark, running in the light."*
